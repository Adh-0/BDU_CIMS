# BDU CIMS

BDU CIMS is a university-focused information system built for Bharathidasan University. The project was designed to help students and visitors find answers about admissions, fees, courses, and related academic information through a guided question-and-answer experience.

## Project Overview

The system was originally built as a retrieval-augmented chatbot that reads from official university documents and returns focused answers based on those sources. The goal is to make common student queries easier to handle while keeping the information tied to institutional documents rather than free-form answers.

## What The Project Covers

- Frequently asked questions about admissions, eligibility, fees, programs, and course-related documents
- Document-backed question answering
- A web-based interface for student support

## Version History

- `v0.1` - Initial proof of concept for document-based student support
- `v1.0` - Expanded question answering workflow and organized the project structure
- `v2.0` - Finalized the public archive and refined the project summary

## Design Goals

- Keep answers aligned with official university material
- Reduce repetitive manual support queries
- Provide a simple, student-friendly experience
- Organize the system so future updates can be added cleanly

## High-Level Structure

The project was organized into separate layers for:

- Document ingestion and preprocessing
- Retrieval and ranking of relevant information
- Answer generation
- Frontend interaction
- API delivery
